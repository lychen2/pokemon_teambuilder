# 结阵 Sixfold v0.1.1

环境页重新设计，优先展示速度与对局分析，规则与数据管理集中到可展开区域。

- 新增当前真实配置的速度表、输出目录和对应耐久分析。输出与结果左右联动，支持搜索、计算条件调整和原始来源查看。
- 显示最高乱数生存情况，以及减少 1 点 HP、防御或特防后是否可能被击倒；保护效果单列，计算边界不当作原作者意图。
- 实战记录保留当时的具体计划路线，实际选出需显式填写；支持按队伍配置、比赛类别和对手筛选列表与统计。
- 修复保存另一组首发时场地与 Mega 条件不一致的问题。
- 在计划、选出、方案比较和环境分析等区域增加宝可梦图像，改善对比度与窄窗口布局。
- 搜索同层复用候选标识，减少重复选出评价。已有对照输出等价，三秒完整构筑目标仍未通过。

共享队伍样本频次不代表排位使用率。耐久结果依赖所选天气、场地、形态与状态。

Windows 安装包未做代码签名，首次运行可能显示 SmartScreen 提示。
