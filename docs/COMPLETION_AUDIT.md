# 原始要求与交付核对

历史验收基准：应用 0.3.0，算法 mc-1.4.0。2026-09-18 补充当前源码 `0.1.0 / mc-1.6.0` 的搜索性能与核心测试证据，见[搜索对照](reports/search-cache-mc-1.6.0.md)；其余历史验收未在本次重跑。原始 19 项任务及验收方法保存在 [OPTIMIZATION_REQUIREMENTS.md](OPTIMIZATION_REQUIREMENTS.md)，未按现有实现缩减要求。测试数字、输入版本和发布文件见 [VALIDATION.md](VALIDATION.md)。

19 项均已有对应实现与可复查入口。策略质量、真实选出效果、独立实战、人工读屏及长时间运行仍有验收缺口，不能据此称为“19 项全部验收完成”。

## 0.1.1 补充

环境页新增全部当前真实配置的速度、输出与耐久分析，并以左右联动展示减少一点耐久后的生存边界。实战记录保留不可改写的具体计划路线，实际选出默认未知，列表与统计共用配置、类别和对手筛选。另选首发保存对应场地与 Mega 条件，主要分析与复盘入口增加宝可梦图像。核心类型检查及 82 项测试通过；当前桌面和发布验证见 [VALIDATION.md](VALIDATION.md)，调研及计算边界见[本轮报告](reports/environment-workflow-0.1.1.md)。这些交付不替代独立实战、作者意图或人工设备证据。

## 四阶段交付对应

- 数据与规则：三张共享表、PokePaste原文、字段完整性、合法性、版本快照和候选更新已进入应用。
- 核心构筑：中文搜索、真实配置筛选、锁定、编辑、自动保存、撤销/重做、导入/导出和重启恢复已实际运行。
- 快速闭环：聚类、真实配置后验、伤害/速度、搭档/补齐/替换、配点目标和改动对照已实际运行；强度提升不作已证实结论。
- 深入评估与发布：真实回合、隐藏信息隔离、同时行动、种子复现、取消、对照报告与Linux包已实现；发布形式及逐项运行结果以验收记录为准。

## 结论边界

当前可交付的是本地构筑、规则迭代和可复查分析工具。没有将专家复盘、物理设备检查、多小时稳定性或独立排位效果写成已经通过。保留原验收要求及失败案例，避免用功能数量替代有效性。
