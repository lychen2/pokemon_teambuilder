# 优化项目实施与验收

本表对应公开资料研究中的 19 项明确条目，更新至应用 0.3.0 / 算法 mc-1.4.0。P0 关注结论可信度，P1 关注构筑工作流，P2 关注资料与维护。功能交付、开发集结果和独立实战证明分别记录，不能互相替代。原始依据见 [RESEARCH.md](RESEARCH.md)，冻结要求见 [OPTIMIZATION_REQUIREMENTS.md](OPTIMIZATION_REQUIREMENTS.md)，未完成的验收见 [COMPLETION_AUDIT.md](COMPLETION_AUDIT.md)。

## P1：可复查的构筑工作流

| ID | 已实现 | 验证与限制 |
|---|---|---|
| P1-1 多路线计划 | 对手六只、多个选出/首发、赢法、担忧与验证状态，留在当前队伍上下文 | 桌面保存两条路线并重启恢复；计划是用户记录，不冒称算法最优 |
| P1-2 实战记录 | 实际选出、结果、原因、回放链接、训练/比赛类别及不可改写队伍快照 | 修改队伍后原快照保留；缺失胜负和选出单独统计；不将个人训练记录当独立算法评测 |
| P1-3 速度到配点 | 具体速度目标携带形态、场地、顺风和状态进入配点求解 | 种子轻装与顺风条件回归；自然速度和实际行动速度分开，同速不写成确定先手 |
| P1-4 条件模板 | 保存不同对手、削血、天气失去等多个条件；伤害、速度、配点复用同一上下文 | 实际界面保存三场景模板并在配点中读取；目标只保证列出的场景 |

| P1-6 来源与变体 | 原作者、分享者、来源意图、配点成熟度、改动说明与变体链；完整保留8885份真实配置及其来源 | 中英文筛选非代表配置、配点和来源一致性、偏好保存及旧记录升级已通过；引文须在原文中，作者未写的意图保持未知 |
| P1-7 风险与替代 | Showdown 命中事件、含落空的击杀概率、多段命中、反伤与合法替代招式；显示计算条件 | 天气命中、多次落空与替代合法性回归；不包括全部跨回合风险、畏缩、命中/闪避等级和接触反伤 |

## 保留的产品边界

- 软权重和笔记由用户填写，不从没有记录的用户身上推断熟练度或风险偏好。
- 独立资料提供证据导入与人工核对；不自动把 RMT 解读写成作者原话。
- Pikalytics、MunchStats、LabMaus 等没有被冒充为已经接入的当前排位统计；共享表仍是初始构筑来源。
- BO3 跨局信息学习、强化学习训练、GPU、公网自动升级、云同步和 Windows/macOS 分发不属于本次已验收能力。
- 规则更新沿候选编译、机制验证、激活和迁移路径进行；已有结果保留原上下文。发布与复查入口见验收文档。
