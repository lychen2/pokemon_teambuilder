# Poke Teambuilder 实施记录

目标：M-C 封闭队表排位的本地桌面构筑应用。技术栈 Electron、React、TypeScript、SQLite；核心构筑、真实数据、可核验计算、渐进深入评估。

## 验收里程碑

- [x] 版本化 Showdown/伤害引擎，支持规则更新与本地检出目录
- [x] M-C/M-B/M-A 原始数据、去重观察、完整性、历史迁移
- [x] 类型化领域模型、SQLite 草稿/修订/快照
- [x] 构筑工作台、锁定、编辑、撤销、导入导出、版本比较
- [x] 自适应聚类、配置后验、条件搭档、伤害/速度分析
- [x] 约束束搜索、局部改进、Pareto 方案与配点搜索
- [x] 公开观察隔离的 Showdown 模拟、信息集搜索、选出/首发
- [x] 算法对照、UI 流程测试、Linux 构建与打包入口

## 固定规则

规则来自 Showdown Dex/TeamValidator；统计来源与真实胜率区分；历史样本不混入当前频率；缺失字段不填假值；前后 Mega 状态分别保留；所有结果绑定队伍、规则、语料、算法修订。错误显式展示。

完整数据、规则/机制回归、桌面流程、算法基线、真实性边界及成品验证见 [VALIDATION.md](VALIDATION.md)。
